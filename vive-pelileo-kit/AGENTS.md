# Instrucciones para Codex — Vive Pelileo

Esta noche Claude Code construye la demo completa. Codex es **opcional** y entra mañana como revisor.

Si te piden revisar:
1. Lee `BRIEF.md`, `PROGRESO.md` y `DECISIONES.md`.
2. Corre `npm run build` y `node scripts/screens.mjs`.
3. Revisa responsive (360, 390, 768, 1024, 1440, 1920), consola, todos los botones y 30 entradas aleatorias a Gaia (vacío, inglés, emojis, "playa", "$10 para 6 personas").
4. Entrega una lista priorizada de problemas en `REVISION_CODEX.md`. Corrige solo bugs claros; no cambies el diseño.
5. Español neutro con "tú" en cualquier texto que toques.
